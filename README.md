# CTS - Chiller Technical Services

**Live Site:** [cts-drchillar.vercel.app](https://cts-drchillar.vercel.app/)

A modern, responsive business website built for **Chiller Technical Services L.L.C.**, an HVAC and industrial cooling solutions provider based in Ajman, UAE. The site showcases the company's products, services, and blog content, and serves as the primary digital storefront for customer inquiries.

---

## 📌 Overview

CTS - Chiller Technical Services specializes in water chillers, cooling towers, A/C units, cold rooms, and related maintenance services across the UAE. This website was built to give the company a professional online presence with clear navigation across its offerings, an integrated blog for SEO and customer education, and direct channels (WhatsApp, phone, email) for lead generation.

---

## ✨ Features

- **Responsive design** — optimized for desktop, tablet, and mobile
- **Dynamic Product & Service pages** — dedicated pages for each offering (Water Chillers, Heat Exchangers, A/C Units, Cold Rooms, AMC, etc.)
- **Blog section** — articles on maintenance tips, rentals, and industry insights
- **Direct contact integrations** — WhatsApp click-to-chat, phone, and email links
- **Optimized image delivery** — using Next.js Image Optimization for fast load times
- **SEO-friendly structure** — meta descriptions and semantic markup for search visibility

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/abints47/CTS-drchillar-project.git

# Navigate into the project directory
cd CTS-drchillar-project

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

### Building for Production

```bash
npm run build
npm start
```
